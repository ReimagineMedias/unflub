## Fields

**Name:** unflub

**Website:** https://unflub.rmgn.net

**Short description:**

> Phone-style autocorrect for every text field on Windows. Fixes typos as you type, offline, and leaves code
> and passwords alone.

**Full description:**

> unflub fixes a typo the moment you finish the word, in any app on Windows: browsers, chat apps, AI prompt
> boxes, email and editors. Press Backspace right after a fix to get your word back, and unflub stops fixing
> that word.
>
> It decides in about 0.1 ms per word and uses about 20 MB of memory in the background, with no CPU while
> you're not typing. Terminals, password fields and password managers are skipped by default. In code
> editors it fixes comments and leaves camelCase, snake_case, paths and anything in backticks alone.
>
> Nothing you type leaves your computer. It checks for updates daily without an ID. Anonymous usage counts
> and crash reports are on by default, with a choice on first run and a switch in Settings.
>
> Free and open source under the MIT license. Windows now, macOS and Linux next. English only for now.

**Platforms:** Windows. Add macOS and Linux only when they ship.

**License:** Free, Open Source (MIT). Source: https://github.com/ReimagineMedias/unflub
